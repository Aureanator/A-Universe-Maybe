The complete basement-to-capstone summary and programming specification for a local simulation agent is as follows.

The basement axiom is: directed implications reduce. This means that if an implication is binding and its precondition is resolved, its consequence is resolved. Nothing else is assumed at the basement. No space, no time, no matter, no energy, no observer, no continuum, no coordinates.

From the axiom, the first necessary structure is a set of events. Let $\mathcal{E}$ be the set of events. An event is a primitive actualization, not a point in space. The second necessary structure is a directed implication relation. If $A, B \in \mathcal{E}$, then $A \to B$ means event $A$ implies event $B$. This relation is directed. In general, $A \to B$ does not imply $B \to A$. This directedness is the first seed of temporal orientation.

The next step is reduction. A possible implication is written $A \to B$. An actualized implication is written $A \Rightarrow B$. Reduction is the operation by which an implication becomes realized. The set of realized reductions generates a causal order. Define $A \prec B$ if there is a chain of realized reductions from $A$ to $B$. This partial order is not embedded in time. It is time. Therefore, time emerges as causal precedence.

Once events and directed implications exist, the next necessary addition is constraint. Each implication carries a constraint label from a group $G$. For an implication $A \to B$, assign $A_{AB} \in G$. The label is the obligation that must be satisfied for the implication to reduce. In the electromagnetic continuum limit, $G = U(1)$. In the finite tetrahedral seed, $G = A_4$. For early simulation, $G = \mathbb{Z}_3$ is acceptable as a simpler test group, but the architecture should be group-generic.

Given constrained implications, cycles become physically meaningful. A cycle is a sequence $C = e_1 \to e_2 \to \cdots \to e_n \to e_1$. The holonomy of the cycle is the ordered product of constraint labels around the cycle:

\[
\Phi_C = \prod_{(i,j) \in C} A_{ij}.
\]

If $\Phi_C = e_G$, the cycle fully reduces. If $\Phi_C \neq e_G$, the cycle partially reduces and leaves a residue. That residue is charge:

\[
Q_C = \Phi_C.
\]

Thus charge is not a substance. It is the nontrivial holonomy of a cyclic constraint that fails to close cleanly.

The labels $A_{AB}$ are gauge-dependent. A local gauge transformation assigns a group element $\lambda_A$ to each event and transforms the edge label as

\[
A_{AB} \to \lambda_A^{-1} A_{AB} \lambda_B.
\]

The holonomy around a closed cycle transforms by conjugation:

\[
\Phi_C \to \lambda^{-1} \Phi_C \lambda.
\]

Therefore the conjugacy class of the holonomy is gauge-invariant. Physical charge is not the raw edge label. It is the gauge-invariant residue of a closed constraint loop.

Conservation arises when we define legitimate local updates correctly. An arbitrary rewrite of an edge label is not a physical reduction. A physical internal resolution must preserve the unresolved constraint presented to the outside. For a region $R$, an allowed update must satisfy

\[
\Phi_{\partial R}^{\text{before}} \sim \Phi_{\partial R}^{\text{after}},
\]

where $\sim$ means same conjugacy class. If the boundary residue is preserved, local internal changes cannot create or destroy net external charge. Thus conservation is not added as a separate law. It is the condition for a rewrite to count as a legitimate resolution.

The next step is the emergence of 3D geometry. The minimal relational structure capable of supporting nontrivial local cyclic closure is the boundary of the tetrahedron, $\partial \Delta^3$. It has 4 vertices, 6 edges, and 4 triangular faces. Its orientation-preserving automorphism group is $A_4$. The natural representation of $A_4$ is constructed from $\mathbb{R}^4$ by quotienting the diagonal subspace:

\[
W = \mathbb{R}^4 / \mathbb{R}(1,1,1,1).
\]

This gives $\dim W = 3$. The crucial identity is

\[
\wedge^2 W \cong W.
\]

This identity is unique to three dimensions. It gives the cross product and the Lie algebra $\mathfrak{so}(3)$. The dimensional selection equation is

\[
d = \frac{d(d-1)}{2},
\]

whose nontrivial solution is $d = 3$. Therefore 3D rotational structure is not assumed. It is selected by relational closure.

Translations emerge by extending to the boundary of the 4-simplex, $\partial \Delta^4$. Its symmetry structure, in the local flat contraction, yields the Euclidean algebra

\[
\mathfrak{e}(3) = \mathbb{R}^3 \rtimes \mathfrak{so}(3).
\]

Therefore the sequence is: cycle, tetrahedron, rotations, translations, 3D Euclidean relational geometry.

Matter is then defined as a persistent relational structure. Let $F$ be the reduction operator acting on relational structures. A structure $O$ is persistent if

\[
F(O) \cong O.
\]

Matter is a persistent topological fixed point of reduction. It is not a substance. It is a pattern of constraints that survives reduction. Its persistence is protected by topological invariants. If $\tau(O)$ is a nontrivial invariant and local reductions preserve $\tau$, then $O$ cannot be reduced to nothing.

Mass is the structural resistance of a persistent object to reconfiguration. If $\Delta O$ is a change in the object, define a reconfiguration cost $\mathcal{C}(\Delta O)$. Then

\[
m(O) \propto \mathcal{C}(\Delta O_{\text{unit}}).
\]

Mass is not primitive. It is the cost of moving or deforming a persistent constraint knot.

The distinction between light-like direct implication and matter is resolution multiplicity. A direct implication has one clean resolution:

\[
A \Rightarrow B.
\]

Matter has hidden internal ambiguity. Given a fixed external boundary $B$, there may be multiple inequivalent internal resolutions $r_i$ such that

\[
\partial r_i = B.
\]

The internal state space is

\[
\mathcal{I}(B) = \frac{\text{admissible internal resolutions of } B}{\text{boundary-indistinguishable equivalence}}.
\]

If $|\mathcal{I}(B)| = 1$, the process is direct or light-like. If $|\mathcal{I}(B)| > 1$, the process carries hidden matter-like internal state. Matter is not light because its interaction state is not uniquely determined by the external boundary.

Quantum structure arises from these internal resolution spaces. The residual gauge group preserving a boundary charge $q$ is the centralizer

\[
H = C_G(q).
\]

The internal resolutions form a representation of $H$. Decomposing that representation into irreducible representations gives primitive quantum sectors. For $G = A_4$ and $q$ of order 3, $H \cong \mathbb{Z}_3$, and the sectors carry discrete phase labels $1, \omega, \omega^2$, where $\omega = e^{2\pi i/3}$. Interactions combine representation spaces by tensor product:

\[
\mathcal{H}_1 \otimes \mathcal{H}_2.
\]

Allowed outcomes are invariant couplings, or singlet sectors, of the combined representation.

Measurement is not mystical. It is a physical constraint interaction between the system and a probe. The probe must couple to the system as a dual representation. If the system is in state $|\psi\rangle$, and $P_k$ projects onto outcome $k$, then the number of valid joint resolutions leading to outcome $k$ is

\[
N_k = \operatorname{Tr}(P_k |\psi\rangle \langle \psi|).
\]

This gives

\[
N_k = |\langle k | \psi \rangle|^2.
\]

After normalization,

\[
P(k) = |c_k|^2.
\]

Thus the Born rule is not a separate axiom. It is the normalized count of valid bilinear constraint resolutions between a system and a dual probe.

Gravity emerges from event density. Spacetime is not a container populated by events. Spacetime is the event mesh. A massive object is a persistent knot of constraints with high internal event density. Near such an object, the mesh is literally finer. Let $\rho(x)$ be the local event or interaction density. Let $\rho_0$ be the baseline vacuum density. Then

\[
\rho(x) = \rho_0 + \Delta \rho(x).
\]

An observer who coarse-grains over microscopic events perceives this variable mesh density as geometry. Define an effective density factor

\[
n(x) = \frac{\rho(x)}{\rho_0}.
\]

Where $n(x)$ is larger, the mesh is finer, and signals require more microscopic reductions to traverse the same coarse-grained distance. This produces propagation delay, time dilation, and apparent curvature.

Gravitational time dilation follows because a clock is a repeating cycle of events. In a finer mesh, one coarse clock tick requires more microscopic event steps. Relative to a distant coarse-mesh observer, the dense-mesh clock advances more slowly.

Spatial curvature follows because density gradients distort coarse-grained geometric relations. Circumferences, radial distances, and path lengths measured in event counts no longer match flat-mesh expectations. In the weak limit this gives a Poisson-like relation,

\[
\nabla^2 \Phi = 4\pi G \rho,
\]

and covariantly,

\[
G_{\mu\nu} = 8\pi G T_{\mu\nu},
\]

where $G_{\mu\nu}$ describes coarse-grained mesh curvature and $T_{\mu\nu}$ describes the density and flux of persistent event-generating structure.

Geodesic motion is the natural path of a persistent structure through a nonuniform event mesh. A free object follows a path that extremizes its proper event count. Because massive regions densify the mesh, the extremal path bends toward higher interaction density. The observer sees this as gravitational attraction.

The capstone is therefore: binding directed implications generate causal order; constrained cyclic implications generate charge; tetrahedral closure selects 3D geometry; persistent topological closures become matter; reconfiguration cost becomes mass; hidden internal resolutions become quantum states; measurement as dual coupling yields the Born rule; massive persistent structures densify the event mesh; the observer coarse-grains that density as curved spacetime; gravity is the geometry of interaction density.

The agent must not build a normal particle engine. It must not make continuous 3D space fundamental. It must build a discrete event-constraint-simplicial simulator. Coordinates are only for visualization. The fundamental dynamics must be relational and combinatorial.

The third module is holonomy. For each triangular face, compute

\[
\Phi_{ijk} = A_{ij} A_{jk} A_{ki}.
\]

Snippet:

def faceHolonomy(face):
    a = face.edgeIJ.label
    b = face.edgeJK.label
    c = face.edgeKI.label
    return Group.multiply(Group.multiply(a, b), c)

For a region boundary, compute the boundary holonomy by multiplying labels around the oriented boundary loop.

Snippet:

def boundaryHolonomy(region):
    result = Group.identity()
    for edge in orientedBoundaryEdges(region):
        result = Group.multiply(result, edge.label)
    return result

The eighth module is 3D dynamics using local topology-preserving moves. For a more genuine 3D simulation, implement Pachner moves. These are local moves that change the internal triangulation while preserving the boundary.

The agent should also count joint internal resolutions. If two objects have internal resolution spaces $\mathcal{I}_1$ and $\mathcal{I}_2$, and they share a boundary face $F$, the joint space is a fiber product:

\[
\mathcal{I}_1 \times_F \mathcal{I}_2.

If this space is empty, the interaction is forbidden. This is a primitive exclusion mechanism.

def jointResolutionCount(objA, objB, sharedFace):

Milestone 1: finite tetrahedral seed. Implement $A_4$, tetrahedron, gauge fixing, holonomy, and enumeration. Reproduce 1728 raw gauge-fixed configurations and 178 gauge classes.

Milestone 2: boundary-preserving dynamics. Implement elementary generator moves and accept only moves preserving boundary holonomy class. Log accepted and rejected moves. Measure transition graph connectivity.

Milestone 5: motion cost. Move the defect one combinatorial cell using accepted local rewrites. Measure the rewrite cost. This is the first mass proxy.

Milestone 8: 3D visualization. Render the tetrahedral mesh, holonomy classes, persistent objects, and observer density field. Use coordinates only as a projection.
